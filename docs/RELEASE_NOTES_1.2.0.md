# Parsy 1.2.0

Крупное обновление разбора: локальная история, детальный разбор раундов, карта активности, командный отчёт и чат с AI-тренером.

## Что нового

- **История и прогресс.** Матчи сохраняются в локальной SQLite-базе. Во вкладке «Игрок» появился график ADR и таблица последних матчей; текущий матч подсвечивается.
- **Разбор раундов.** Вкладка «Раунды» показывает результат, счёт, сторону, K/D/A, урон, первую дуэль, мультифраги, клатчи и автоматические теги: entry, trade, clutch, teamflash, no plant/no defuse и другие.
- **Карта активности.** Вкладка «Карта» строит плотность позиций, точки смертей и убийств, а также маркеры сайтов плента. Radar-подложка не используется, поэтому карта является координатной схемой.
- **Командный отчёт.** Вкладка «Команда» показывает роли по статистике, записи на сторонах, пленты, сравнение с соперником и выгрузку CSV.
- **AI-чат.** Можно спросить про конкретный раунд, причины поражения, слабые места, карты и тренировки. Локальный режим работает без интернета; внешний API получает только сжатый контекст.
- **Быстрый старт.** Кнопка «Последняя демка Steam» ищет самый свежий `.dem` в библиотеках Steam. Папку можно переопределить через `PARSY_DEMO_DIR`.
- **Экспорт.** JSON-отчёт по всему матчу, CSV по раундам, CSV по команде и Markdown-план тренировок.
- **Автоподхват игроков.** История сохраняется для всех участников демки, а не только для выбранного игрока.

## Улучшения

- Нормализация сайтов плента для отображения A/B.
- Более корректный счёт матча: учитываются завершённые раунды, а не только список `round_start`.
- Раунды без победителя (рестарты и технические паузы) не попадают в статистику игроков, карту, командный отчёт и экспорт.
- Кэш разобранной демки обновлён для новых полей позиций.
- Добавлены адаптивные правила для раундов, состава и чата на узких экранах.
- Добавлена зависимость `history.py` в сборку PyInstaller.

## Установка

### С установщиком

1. Скачай `Parsy-Setup-1.2.0.exe`.
2. Запусти установщик.
3. Если SmartScreen покажет предупреждение, нажми «Подробнее» → «Выполнить в любом случае». Установщик не подписан код-сертификатом.
4. Запусти Parsy из меню «Пуск» или с рабочего стола.

Обновление с `1.0.0`/`1.1.0` выполняется поверх установленной версии. История, настройки и профили сохраняются. Права администратора не нужны.

### Portable

1. Скачай `Parsy-Portable.zip`.
2. Полностью распакуй архив в отдельную папку.
3. Запусти `Parsy.exe`.

Portable-версия обновляется заменой папки.

## Данные и приватность

- История: `%LOCALAPPDATA%\Parsy\history.db`.
- Логи: `%LOCALAPPDATA%\Parsy\logs`.
- Демки не отправляются на сервер и не сохраняются в историю.
- Для про-карточек передаются только никнеймы и названия команд.
- Внешнему AI API отправляются только рассчитанные метрики и никнейм; демка не загружается.

## Требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime.
- Около 450 MB свободного места.
- Интернет — для карточек Liquipedia, проверки обновлений и опционального AI API. Локальный разбор, история и AI-план работают без сети.

## Ограничения

- Radar-ассетов CS2 в сборке нет: карта активности показывает координатную схему.
- Внешний AI API не проверяется без ключа/локальной модели. Ответы модели могут содержать ошибки.
- Автообновление доступно только для установленной версии.
- Интерфейс и документация на русском языке.
