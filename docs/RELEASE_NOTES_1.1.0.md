# Parsy 1.1.0

Обновление с AI-тренером и автообновлением установленной версии.

## Что нового

- Вкладка «AI-тренер»: главный вывод по матчу, слабые метрики, упражнения, карты для тренировки и план на 5 дней.
- Локальный анализ работает без интернета и не отправляет демку.
- Опциональное подключение Ollama или OpenAI-совместимого API: DeepSeek, OpenAI, OpenRouter и свой endpoint.
- Внешнему AI отправляются только рассчитанные метрики и никнейм; API-ключ хранится в текущей сессии.
- Проверка обновлений в боковой панели установленной версии.
- Скачивание Setup с GitHub, проверка размера и SHA-256, тихая установка и автоматический перезапуск.
- Обновление сохраняет настройки, профили и пользовательские данные.
- Portable-версия показывает ссылку на GitHub и обновляется заменой папки.

## Установка

### Вариант 1. Установщик

1. Скачай `Parsy-Setup-1.1.0.exe`.
2. Запусти установщик.
3. Если SmartScreen покажет предупреждение, нажми «Подробнее» → «Выполнить в любом случае». Установщик не подписан код-сертификатом.
4. Запусти Parsy из меню «Пуск» или с рабочего стола.

Права администратора не нужны. Установка идёт в `%LOCALAPPDATA%\Programs\Parsy`.

Если Microsoft Edge WebView2 Runtime отсутствует, установщик запустит официальный bootstrapper Microsoft. Нужен интернет.

### Вариант 2. Portable

1. Скачай `Parsy-Portable.zip`.
2. Полностью распакуй архив.
3. Запусти `Parsy.exe`.

WebView2 Runtime должен быть установлен в системе.

## Обновление с 1.0.0

Установленная версия 1.0.0 не содержит updater, поэтому первый переход на 1.1.0 выполняется вручную: скачай и запусти `Parsy-Setup-1.1.0.exe`. Дальше обновления доступны из боковой панели Parsy.

## Требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime.
- Около 450 MB свободного места.
- Интернет для карточек команд, проверки обновлений и внешнего AI API. Разбор демки и локальный AI-план работают локально.

## Приватность

- Демка не отправляется на сторонние сервера.
- Локальный сервер слушает только `127.0.0.1` и закрывается вместе с приложением.
- Для карточек про-команд могут передаваться никнеймы и названия команд.
- При подключении внешнего AI API отправляются только метрики и никнейм.
- Для проверки обновлений приложение обращается к GitHub API; установщик проверяется по SHA-256.
- Логи: `%LOCALAPPDATA%\Parsy\logs`.

## Известные ограничения

- Приложение не подписано код-сертификатом: возможно предупреждение SmartScreen.
- Автообновление доступно только для установленной версии; Portable обновляется вручную.
- Для карточек команд, обновлений и внешнего AI API нужен интернет.
- Ответы внешней AI-модели могут содержать ошибки.
- Интерфейс и документация на русском языке.
